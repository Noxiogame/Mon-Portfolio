# Portfolio de Mateo Leuillier

Portfolio personnel en HTML, CSS et JavaScript, avec Vite pour le serveur de développement et la build de production.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir l'adresse locale indiquée par Vite.

## Structure

- `index.html` : structure des sections et contenu du portfolio.
- `styles.css` : identité visuelle, responsive design et animations.
- `script.js` : filtres projets, curseur lumineux et fenêtre de détail.
- `package.json` : scripts de développement et de production.

Les visuels des projets sont construits en CSS pour garder le projet autonome. Ils peuvent être remplacés par des captures ou images finales dans les blocs `.project-art`.
